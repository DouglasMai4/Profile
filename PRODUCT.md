# Product

## Platform

web

## Users

- **Developers / OSS community** — peers arriving via Kori, GitHub or a shared blog post, judging technical depth.
- **Freelance / agency clients** — businesses evaluating Douglas or Kingdom Softwares for custom-built software.
- **Recruiters / employers** — people assessing Douglas as a Full Stack hire.

All three matter; none is subordinate.

## Product Purpose

Personal portfolio and blog of Douglas Maia, Full Stack developer (douglasmaia.dev.br). The primary action is **reading the blog**: writing is how credibility is built. Projects and contact channels support that credibility and convert it.

## Positioning

A working developer's own site: real projects he builds or works on (Kori, Goalfy, Kingdom Softwares) plus his own writing, in Portuguese first.

## Operating Context

- Bilingual: **pt-BR primary** at `/`, **EN secondary** at `/en/`. Brazilian audience first; EN for reach.
- Blog posts in Markdown via Content Collections, one file per locale.
- Contact channels: WhatsApp, LinkedIn, GitHub, Telegram, email.

## Capabilities and Constraints

- Astro 7 + Tailwind CSS 4, fully static, no client-side framework; interactive touches are small vanilla scripts (particle background, scroll spy, language switcher, encrypted-text effect).
- SEO: canonical, hreflang, Open Graph, Twitter cards, JSON-LD, localized sitemap.
- Vercel Analytics and Speed Insights; deployed on Vercel. Package manager: bun.
- Every user-facing string lives in `src/i18n/locales/` and must exist in both languages.

## Brand Commitments

- Name: Douglas Maia. Title: Full Stack Developer.
- Douglas is founder of Kingdom Softwares and currently a developer at Goalfy.

## Evidence on Hand

- Projects: Kori (Go HTTP toolkit on Chi, open source), Goalfy (CRM 360 with AI/WhatsApp, private), Kingdom Softwares (his software house).
- Blog: one post so far ("Do React ao Astro"), in both locales.
- No testimonials, client logos, metrics or case studies exist — do not fabricate them.

## Product Principles

1. Writing leads: the blog is the main destination, not an afterthought.
2. Show real work; no invented claims or numbers.
3. Portuguese first, English always in parity.
4. Stay static and fast; performance is part of the pitch.
